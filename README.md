# rashedhindash.github.io

Personal site of Rashed Hindash — portfolio, research outputs (NTROs), writing,
tutorials and tools.

**If you're looking for how to add a post or a video, read [HOW-TO.md](HOW-TO.md).**

---

## What this is

A static site generated by a single Python script. No Node, no npm, no
framework, no dependencies outside the standard library. If Python runs, this
builds.

```bash
python build.py            # build into _site/
python build.py --serve    # build, preview at localhost:8000, rebuild on save
python build.py --drafts   # include files marked draft: true
```

On Windows, `Preview.cmd` and `Publish.cmd` wrap those for day-to-day use.

## How it fits together

| Path | Role |
| --- | --- |
| `content/site.json` | Global config: name, tagline, accent, nav, links |
| `content/<collection>/*.md` | Content. Front matter + Markdown |
| `theme/base.html` | The page shell. `{{token}}` placeholders |
| `theme/style.css` | All styling. `{{accent}}` is injected at build time |
| `theme/app.js` | Theme toggle, reveals, embed facades, prefetch |
| `build.py` | Front matter parser, Markdown renderer, page templates |
| `_site/` | Build output. Git-ignored; CI regenerates it |

Collections are declared in `COLLECTIONS` in `build.py`. `docs` is special —
each entry joins a tool via its `tool:` field and renders at
`/tools/<tool>/<slug>/`. `pages` renders flat at `/<slug>/`.

## Markdown extensions

Beyond standard Markdown:

```
::video <drive|youtube|vimeo|.mp4 url> | caption
::image /static/images/x.jpg | caption
::grid  /static/a.jpg | /static/b.jpg
::note  Text for a callout box.
```

Video embeds render as a click-to-load facade — no third-party iframe or script
loads until the visitor presses play.

## Deployment

Push to `main`. `.github/workflows/deploy.yml` builds with Python 3.12 and
deploys to GitHub Pages. Roughly 30 seconds end to end.

To move to a custom domain, set `custom_domain` in `content/site.json`; the
build writes the `CNAME` file for you.

## Design notes

- Dark by default, light via toggle, honours `prefers-color-scheme` when unset.
- One accent colour, driven from `site.json` through to the favicon.
- Motion budget: nothing exceeds 460ms. Easing is `cubic-bezier(.16,1,.3,1)`.
- Cross-page transitions use the native View Transitions API — no library, and
  a silent no-op where unsupported.
- `prefers-reduced-motion` disables all of it.
- No web fonts, no external CSS or JS. The only third-party requests are video
  thumbnails, and only on pages that embed video.
